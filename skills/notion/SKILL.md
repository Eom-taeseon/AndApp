# 📋 폰슐랭 데일리 보고 스킬

> 바이브 코딩 작업 내용을 노션에 자동 정리하는 스킬

---

## 목적

폰슐랭 프로젝트의 작업 내용을 **노션 "토이 프로젝트 진행 일지" DB**에 자동 기록한다.
하루 2회(오전 6시, 오후 6시) 실행되어 작업 내역을 정리·보고한다.

---

## 노션 DB 정보

- **DB 이름**: 토이 프로젝트 진행 일지
- **DB URL**: https://www.notion.so/31ed57c78fa080d4a36edaf94a38bc21
- **Data Source ID**: `31ed57c7-8fa0-802e-a0d7-000bfb4f44c6`
- **상위 페이지**: 폰슐랭

### DB 스키마

| 속성 | 타입 | 설명 |
|---|---|---|
| 날짜 | Title | 보고 제목 (예: "2026-03-09 오전 보고") |
| 요약 | Text | 작업 내역 요약 (마크다운) |
| 사람 | Person | 작성자 |

---

## 실행 스케줄

| 시간 | Cron 표현식 | 보고 유형 |
|---|---|---|
| 오전 6:00 | `0 6 * * *` | 오전 보고 (전일 오후~금일 오전 작업) |
| 오후 6:00 | `0 18 * * *` | 오후 보고 (금일 오전~오후 작업) |

---

## 보고 페이지 형식

### 제목 (날짜 속성)
```
YYYY-MM-DD {오전|오후} 보고
```

### 요약 (요약 속성)
```markdown
## 작업 내역
- [Context명] 작업 내용 1
- [Context명] 작업 내용 2

## 변경 파일
- `src/domains/review/...`
- `src/shared/...`

## 이슈 & 메모
- 발견된 이슈나 다음 작업 메모
```

### 페이지 본문 (content)
```markdown
# {날짜} {시간대} 폰슐랭 작업 보고

## 📋 작업 요약
오늘 작업한 내용을 DDD Bounded Context별로 정리합니다.

## 🔧 상세 작업 내용

### Identity Context
- (해당 작업 없으면 생략)

### Restaurant Context
- (해당 작업 없으면 생략)

### Review Context (Core)
- (해당 작업 없으면 생략)

### Visualization Context
- (해당 작업 없으면 생략)

### Discovery Context
- (해당 작업 없으면 생략)

## 📁 변경된 파일 목록
변경된 파일 경로를 나열합니다.

## 🐛 이슈 & 디버깅
발생한 오류나 해결한 문제를 기록합니다.

## 📌 다음 작업 계획
다음 세션에서 이어서 할 작업을 메모합니다.
```

## 스킬 실행 방법

### 자동 실행 (스케줄)
`scheduled-tasks`로 등록하여 오전 6시, 오후 6시에 자동 실행.

### 수동 실행
사용자가 "오늘 작업 정리해줘", "노션에 기록해줘" 등의 요청 시 즉시 실행.

---

## 구현 로직

1. 현재 시간 확인 → 오전/오후 판별
2. 최근 작업 내역 수집:
   - `skills/domain-driven/bounded-contexts/*/logs/LOG.md` 최신 항목 확인
   - 가능하면 git log에서 최근 커밋 메시지 수집
3. 노션 페이지 생성:
   - `notion-create-pages` 도구 사용
   - `data_source_id`: `31ed57c7-8fa0-802e-a0d7-000bfb4f44c6`
   - 속성: 날짜(제목), 요약(텍스트)
   - 본문: 마크다운 형식의 상세 보고

---

## 주의사항

- 작업 내용이 없는 날에도 "작업 없음" 페이지를 생성하여 연속성 유지
- 보고 제목에 날짜와 시간대를 반드시 포함
- 요약은 3~5줄 이내로 간결하게
- 본문에는 가능한 구체적인 파일 경로와 작업 내용 포함
