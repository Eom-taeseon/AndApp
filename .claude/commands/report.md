# 폰슐랭 데일리 보고

폰슐랭 프로젝트의 작업 내용을 노션 "토이 프로젝트 진행 일지" DB에 기록한다.

## 실행 절차

1. 현재 시간 확인 → 오전(06:00~17:59) / 오후(18:00~05:59) 판별
2. 최근 작업 내역 수집:
   - `git log --oneline -20` 으로 최근 커밋 확인
   - `skills/domain-driven/bounded-contexts/*/logs/LOG.md` 최신 항목 확인
3. 아래 형식으로 노션 페이지 생성

## 노션 DB 정보

- **Data Source ID**: `31ed57c7-8fa0-802e-a0d7-000bfb4f44c6`
- **속성**:
  - `날짜` (Title): `YYYY-MM-DD {오전|오후} 보고`
  - `요약` (Text): 3~5줄 작업 요약

## 페이지 본문 형식

```
# {날짜} {오전|오후} 폰슐랭 작업 보고

## 📋 작업 요약
오늘 작업한 내용을 DDD Bounded Context별로 정리합니다.

## 🔧 상세 작업 내용

### Identity Context
- (해당 작업 없으면 생략)

### Restaurant Context
- (해당 작업 없으면 생략)

### Review Context (Core)
- (해당 작업 없으면 생략)

### Visualization Context
- (해당 작업 없으면 생략)

### Discovery Context
- (해당 작업 없으면 생략)

## 📁 변경된 파일 목록
변경된 파일 경로를 나열합니다.

## 🐛 이슈 & 디버깅
발생한 오류나 해결한 문제를 기록합니다.

## 📌 다음 작업 계획
다음 세션에서 이어서 할 작업을 메모합니다.
```

## 주의사항

- 작업 내용이 없는 날에도 "작업 없음" 페이지를 생성하여 연속성 유지
- `notion-create-pages` 도구 사용
- 요약은 3~5줄 이내로 간결하게
