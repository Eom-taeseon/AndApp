# /preview — 컴포넌트 미리보기 스킬

JSX 컴포넌트의 렌더링 결과를 텍스트로 설명한다. dev server 없이 UI가 어떻게 보일지 파악할 수 있다.

## 사용법

- `/preview {파일경로}` — 특정 컴포넌트 미리보기
- `/preview` — 최근 변경된 컴포넌트 자동 감지

## 인자

`$ARGUMENTS`가 있으면 해당 파일을, 없으면 `git diff --name-only`로 최근 변경된 `.jsx` 파일을 대상으로 한다.

---

## 실행 절차

### 1. 대상 컴포넌트 파일 읽기

- 파일 경로가 주어지면 해당 파일을 읽음
- 없으면 `git diff --name-only`에서 `.jsx` 파일 추출 (최대 3개)

### 2. 컴포넌트 분석

각 컴포넌트에 대해 다음을 분석:

| 분석 항목 | 설명 |
|---|---|
| **Props** | 컴포넌트가 받는 props와 기본값 |
| **State** | useState로 관리하는 상태 변수 |
| **조건부 렌더링** | if/삼항연산자에 의한 분기 |
| **이벤트 핸들러** | onClick, onChange, onSubmit 등 |
| **자식 컴포넌트** | 사용하는 하위 컴포넌트 목록 |
| **스타일** | Tailwind 클래스 기반 레이아웃 추론 |

### 3. UI 시각화 (텍스트)

ASCII 아트 또는 구조화된 텍스트로 UI 레이아웃을 표현한다.

### 4. 결과 출력

```
## Preview: {컴포넌트명}

### Props
- `onSubmit` (function) — 폼 제출 핸들러
- `initialData` (object, optional) — 초기값

### 상태 (State)
- `email` (string, 초기값: "")
- `isLoading` (boolean, 초기값: false)

### UI 레이아웃

┌─────────────────────────────┐
│         로그인               │
│                             │
│  ┌─────────────────────┐    │
│  │ 이메일              │    │
│  └─────────────────────┘    │
│  ┌─────────────────────┐    │
│  │ 비밀번호            │    │
│  └─────────────────────┘    │
│                             │
│  [    로그인 버튼     ]      │
│                             │
│  회원가입 링크               │
│                             │
└─────────────────────────────┘

### 조건부 렌더링
- `isLoading === true` → 버튼 텍스트가 "로딩중..."으로 변경, 버튼 비활성화
- `error !== null` → 에러 메시지 빨간색 텍스트 표시

### 인터랙션
1. 이메일 입력 → `email` 상태 업데이트
2. 비밀번호 입력 → `password` 상태 업데이트
3. 로그인 버튼 클릭 → `onSubmit({email, password})` 호출
4. 회원가입 링크 클릭 → 회원가입 폼으로 전환
```

---

## 에러 처리

- 파일이 존재하지 않으면: 에러 메시지
- `.jsx` 파일이 아니면: 경고 후 진행 시도
- 변경된 `.jsx` 파일이 없으면: 안내 메시지

## 주의사항

- 실제 렌더링이 아닌 코드 분석 기반 추론이므로 100% 정확하지 않을 수 있음
- 동적 데이터(API 응답 등)는 "샘플 데이터" 기반으로 추론
- Tailwind 클래스를 기반으로 레이아웃을 추론하되, 정확한 픽셀 단위는 불가
